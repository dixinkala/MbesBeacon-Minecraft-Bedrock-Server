# 08 监控与计划任务

[← 返回目录](README.md)

## 性能监控（⑦）

| 指标 | 说明 |
|---|---|
| CPU | 服务器进程 CPU 使用率（非阻塞采集，首次采样可能为 0） |
| 内存 | 进程内存占用（MB） |
| 在线玩家 | 当前在线人数 |
| 运行状态 | 运行 / 未运行 |
| TPS | 基岩版服务端不输出 TPS，界面显示 0（预留） |

- 默认每 5 秒自动刷新，可手动关闭自动刷新
- 数值来自系统进程信息，服务器未运行时为空

## 审计日志

记录所有**危险/关键操作**：

| 类别 | 示例 |
|---|---|
| 服务器 | 启动 / 停止 / 重启 / 删除 / 切换 |
| 配置 | 保存配置、配置回滚 |
| 玩家 | 踢出 / OP / 权限变更 / 封禁 / 解封 / 白名单增删 |
| 世界 | 切换 / 重命名 / 删除 / 复制 / 导入 |
| 备份 | 创建 / 打包 / 恢复 / 删除 |

- 每条含时间戳、动作、参数与结果
- 按大小轮转并加锁，轮转期间的条目不会丢
- 可通过日志文件或诊断接口读取，位置见 [11 安全与数据目录](11-security-data.md)

## 计划任务（⑨）

三类任务：

| 类型 | 配置 | 作用 |
|---|---|---|
| 定时重启 | 每天指定时间 / 固定间隔 | 低峰期自动重启 |
| 定时备份 | 每天指定时间 / 每 N 小时 | 自动快照世界 |
| 定时公告 | 每天指定时间 + 消息 | 发送 `say` 全服广播 |

### 行为约定

- **只在服务器运行时执行**；未运行时跳过（不会排队堆积）
- 修改任务后立即生效，无需重启程序
- 任务可启用 / 禁用 / 删除
- 任务列表显示上次执行与下次计划时间

### 补执行机制

若在目标时间点程序未运行，**下次启动后会补执行错过的每日任务**（每类任务只补一次，不会连发多条）。

### 状态持久化

- 执行状态保存在调度器状态文件里，程序重启后不会重复执行同一任务
- 状态与"它属于哪个服务器目录"绑定：切换服务器目录后不会把旧目录的状态写到新目录

## 常见问题

| 问题 | 处理 |
|---|---|
| 任务到点没执行 | 服务器当时未运行；或任务被禁用 |
| 重启后重复执行 | 已做持久化；若仍出现，检查状态文件是否被手动删除 |
| 公告没发出去 | 检查服务器是否在线、任务消息是否为空 |
| 备份任务没生成文件 | 检查磁盘空间与备份保留上限（满额会清理最旧的） |
