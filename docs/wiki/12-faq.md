# 12 常见问题

[← 返回目录](README.md)

## 启动与运行

**Q：首次运行提示「Windows 已保护你的电脑」？**
A：SmartScreen 对未广泛下载的新程序会告警。点「更多信息」→「仍要运行」。程序为开源本地工具，不联网上传数据。

**Q：关闭浏览器页面后服务器还在运行吗？**
A：在。页面只是管理界面，服务器进程独立运行；从托盘或双击 exe 可重新打开。

**Q：如何彻底退出？**
A：控制台「停止服务器」→ 标题栏「退出程序」。

**Q：托盘图标不见了？**
A：点任务栏右下角 `▲` 打开隐藏区域；可把图标拖到任务栏固定。

**Q：启动服务器没反应？**
A：看「性能监控」/控制台提示。常见原因：端口被占用、目录不完整（缺 `bedrock_server.exe`）、杀软拦截。

## 联机与网络

**Q：好友进不来？**
A：按顺序检查：同一网络 → 填的是局域网 IP（不是 `127.0.0.1`）→ 防火墙放行 UDP 19132 → 服务器已启动 → 白名单/正版验证。

**Q：公网怎么开？**
A：路由器做 UDP 端口映射，或用内网穿透；云服务器记得放行安全组。

**Q：下载服务端失败 / SSL 错误？**
A：① 重试；② 勾选「网络异常时跳过 SSL 校验」；③ 用「自定义下载地址」换镜像；④ 确认能访问 `minecraft.net`。

**Q：版本列表加载不出来？**
A：列表来自[自建版本清单](https://github.com/dixinkala/mbesbeacon-bds-versions)，取不到时回退社区清单、再回退内置快照；也可直接手输版本号或用自定义地址。

## 配置与数据

**Q：改了配置不生效？**
A：保存后需重启服务器。

**Q：用户数据在哪？**
A：`%APPDATA%\MbesBeacon\`，详见 [11 安全与数据目录](11-security-data.md)。

**Q：存档在哪？怎么备份？**
A：服务器目录的 `worlds/`；「⑥ 世界备份」可手动/定时备份，更新与删除前也会自动备份。

**Q：端口被占用？**
A：改 `server-port`（如 19133）并重启；启动前会自动做 UDP 占用检测。

## 更新与版本

**Q：怎么更新服务端？**
A：选择服务器后自动检测，或点标题栏「🔄 服务器更新」；更新会自动停服并备份，失败不影响现有服务器。

**Q：怎么更新软件本身？**
A：标题栏「📦 软件更新」→「下载更新」跳转 Release 页面，替换 exe 即可（配置与存档不受影响）。

**Q：官方哈希在哪看？**
A：官方源不提供 SHA256，程序用「版本号官方清单 + PE 签名 + TOFU 基线」组合校验，详见 [11](11-security-data.md)。

## 多服务器

**Q：没检测到我的服务器？**
A：「① 安装服务器」页点「📁 浏览」手动指定目录，之后会记入历史。

**Q：能同时管理多个吗？**
A：可以。启动时检测到多个会弹窗选择，也可在下拉框随时切换；切换会先停掉运行中的服务器。

**Q：切换/删除会丢存档吗？**
A：切换不会。删除分两种模式：「仅删程序」保留存档，「彻底删除」连存档一起删。

## 其他

**Q：支持 Linux 吗？**
A：支持 Ubuntu 20.04+（服务端管理可用；无桌面环境时托盘自动降级）。

**Q：开源协议是什么？**
A：MIT，见 [LICENSE](../LICENSE)。

**Q：遇到没列出的问题？**
A：带日志提 Issue：[提交 Issue](https://github.com/dixinkala/MbesBeacon-Minecraft-Bedrock-Server/issues/new)。附 `%APPDATA%\MbesBeacon\logs` 下相关日志更快定位。
