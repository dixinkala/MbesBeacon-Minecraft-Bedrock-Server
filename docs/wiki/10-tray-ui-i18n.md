# 10 托盘、主题与多语言

[← 返回目录](README.md)

## 系统托盘

| 行为 | 说明 |
|---|---|
| 启动后驻留 | 程序最小化到托盘，图标反映运行状态 |
| 右键菜单 | 打开管理界面 / 启动 / 停止 / 退出程序 |
| 提示文本 | 悬停显示「MbesBeacon — … — 运行中 / 已停止」 |
| 关闭浏览器 | 只关闭界面，服务器继续运行 |
| 重新打开 | 双击 exe 或点托盘图标「打开管理界面」 |

> 退出程序前请先在控制台停止服务器，避免存档写入中断。

## 主题

标题栏「🎨 界面风格」：

- **10 套预设**：Minecraft 暗色、亮色简洁、草方块绿、红石红、钻石蓝、森林绿、海洋蓝、落日橙、紫色科技、粉红少女
- **自定义强调色**：取色器任选
- **明暗模式**：可单独切换（选预设会自动匹配）
- 设置保存到 `theme.json`，下次启动恢复

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+S` | 保存配置 |
| `Ctrl+R` | 重启服务器 |
| `Ctrl+F` | 控制台搜索 |
| `` ` ``（反引号） | 聚焦控制台命令输入框 |
| `↑` / `↓` | 命令历史 / 补全候选切换 |
| `Tab` | 命令补全 |

## 多语言

- 界面中英双语，切换后立即生效并记住选择
- 首次启动跟随系统语言
- 托盘菜单、气泡、提示文本同样跟随
- 控制台日志内容来自服务端，不受界面语言影响

## 显示相关

- 窗口过窄时表格会横向滚动，建议最大化使用
- 深色主题下控制台高亮仍保留红/绿区分
- 缩放系统 DPI 较高时若字小，可在系统显示设置里调整缩放比例
