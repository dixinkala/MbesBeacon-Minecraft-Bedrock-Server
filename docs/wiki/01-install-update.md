# 01 安装与更新

[← 返回目录](README.md)

## 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11；Ubuntu 20.04+ |
| 磁盘空间 | 安装校验要求 ≥ **1200 MB**（暂存目录 + 解压后的服务端同时存在，峰值约为成品的两倍；建议预留 2 GB） |
| 网络 | 需要访问 `minecraft.net`（官方 CDN）或自定义下载地址；版本列表访问 GitHub |
| 权限 | 普通用户即可；无需管理员权限（安装到受保护目录时除外） |

## 首次启动：三步向导

1. **选安装目录**：输入路径或点「📁 浏览」选空文件夹（建议 `D:\MinecraftServer`）
2. **选版本**：点版本框右侧 ▼ 选一个，或直接手输版本号（如 `1.21.0.03`）
3. **开始安装**：安装完成后按勾选项自动启动服务器

不想走向导可点「跳过向导」，在「① 安装服务器」页手动操作。

## 已有服务器：自动检测

启动时会扫描桌面、文档、下载、C/D/E 盘等常见位置查找已安装的服务端：

- 找到 1 个 → 自动管理，不弹窗
- 找到多个 → 弹窗让你选择
- 一个都没找到 → 显示引导横幅，可点「📁 浏览」手动指定目录

手动指定的目录会记入历史，下次启动可直接在「当前服务器」下拉框切换。

## 版本选择

| 来源 | 说明 |
|---|---|
| 版本列表 | 从自建清单仓库 [`dixinkala/mbesbeacon-bds-versions`](https://github.com/dixinkala/mbesbeacon-bds-versions) 联网获取（GitHub Actions 每 6 小时更新）；取不到时回退社区清单，再失败则使用内置快照 |
| 「检测最新版本」 | 从 Mojang 官方 API 取当前稳定版 |
| 手动输入 | 任意版本号，程序会按官方 CDN 规则拼下载地址 |
| 自定义下载地址 | 粘贴第三方/镜像 zip 链接，留空则走官方 CDN |

**版本类型**：

- **稳定版**（默认）：正式发布版本
- **预览版**：含测试特性，可能不稳定；进阶选项「包含稳定版」可把稳定版一并列出

## 下载与安装过程

```
下载 → 本地校验 → 解压到暂存目录 → 逐文件原子并入服务器目录
```

关键点：

- 解压发生在服务器目录下的 `.install_staging`，**合并失败不会破坏现有服务器**
- 合并按文件原子替换：任何一步失败，旧的 `bedrock_server.exe` 仍在
- 合并时保留用户数据：`worlds/`、`server.properties`、`allowlist.json`、`permissions.json`、`banned-*.json` 等不会被官方包覆盖
- 官方内容目录（`resource_packs/`、`behavior_packs/`、`definitions/`）随版本更新
- 安装完成后写入 `.install_manifest.json`，记录本次安装了哪些文件；下次更新只清理"上次装过、新包已移除"的服务端产物，**绝不删除用户文件**

## 完整性校验（每次下载都会做）

| 校验 | 说明 |
|---|---|
| 文件大小 | 低于下限（分块下载不完整）或超出合理范围直接拒绝 |
| ZIP 结构 | 必须能被 `zipfile` 正常打开 |
| 版本号核对 | 版本号需出现在官方版本清单中（清单取不到时跳过，不阻断） |
| SHA256（TOFU） | 首次下载记录哈希；后续同版本对比，不一致中止。清单与签名（HMAC）一同保存，删签名文件不能绕过 |
| PE 数字签名 | Windows 上校验 `bedrock_server.exe` 签名；摘要不匹配/证书伪造**无条件失败**，未签名/非官方来源默认只告警 |

**严格模式**：设置环境变量 `MBES_REQUIRE_SIGNATURE=1` 后，未签名也会中止安装。

> 官方源不提供 SHA256 哈希，TOFU 只能保证"同版本前后一致"，首次下载的可信度取决于下载渠道。

## 服务器更新

- 选择服务器后自动检测一次新版本；有更新弹窗提示，已是最新则静默
- 标题栏「🔄 服务器更新」可随时手动检测
- 更新流程：**停服 → 备份 worlds → 下载并校验 → 暂存合并**
- 更新失败时服务器保持可用（不会先删旧程序）
- 更新完成后需手动启动服务器

## 软件更新（MbesBeacon 自身）

- 启动后延迟 3 秒自动检查一次，有新版本才弹窗
- 标题栏「📦 软件更新」可手动检查
- 弹窗显示当前版本、最新版本、发布时间与更新说明
- 点「下载更新」跳转 GitHub Release 页面下载新 EXE
- 结果缓存 1 小时；主路径解析网页 Release 页面，不消耗 API 配额

## 删除服务器

页面底部红色「删除服务器」卡片，两种模式：

| 模式 | 行为 |
|---|---|
| 仅删除服务端程序 | 保留 `worlds/`、`server.properties`、白名单、权限等，便于换版本重装 |
| 彻底删除整个目录 | 连同世界存档一起删除，**不可恢复** |

- 删除前自动备份 worlds
- 需勾选「我已确认执行删除操作」
- 服务器运行中会先自动停止

## 多实例并行

- 顶部「实例」下拉列出已收录的服务器目录：`●` 运行中 / `○` 未运行 / `✓` 当前实例
- 「➕ 收录当前目录」把当前目录加入列表；「▶ 启动 / ■ 停止」作用于选中的实例，可同时运行多个
- 切换实例只改变"当前实例"，**不会停止其他实例**；每个实例有独立目录、`worlds/` 与控制台
- 常见操作与端口注意事项见 [02 服务器配置](02-config.md) 的「多实例并行」
