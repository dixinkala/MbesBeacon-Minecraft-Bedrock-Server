# 03 控制台与命令

[← 返回目录](README.md)

## 启停与重启

| 操作 | 行为 |
|---|---|
| 启动 | 先做端口占用检测，再拉起服务端进程 |
| 停止 | 发送 `stop` 让服务端自行保存世界后退出；超时无响应再强制结束 |
| 重启 | 停止 → 等待退出 → 重新启动；连续重启有 15 秒限流 |

服务器异常退出会被检测到并记录，界面状态同步更新。

## 实时日志

- **SSE 推送**，延迟通常 < 300 ms，自动滚动到底部
- 最多保留最近 **2000 行**，避免长时间运行吃内存
- 高亮：`ERROR` / `WARN` 标红，玩家连接标绿，关键字区分颜色
- 清空：一键清空显示（后端游标同步重置，不会"复活"旧行）
- 导出：把当前控制台内容导出为 `.txt`
- 搜索：`Ctrl+F` 过滤关键字，基于本地副本，清空日志时搜索状态一并重置

## 命令输入

| 操作 | 快捷键 |
|---|---|
| 聚焦命令输入框 | 反引号键（`` ` ``，Esc 下方） |
| 发送命令 | 回车 |
| 命令历史 | ↑ / ↓ |
| 自动补全 | Tab，或 ↑/↓ 在候选里选 |

- 补全候选由服务端生成，输入 120 ms 内不会重复请求
- 输入为空或服务器未运行时给出提示，不会静默失败

## 危险命令

- 危险命令清单由**后端**统一下发（`/api/commands/dangerous`），前端不再硬编码
- 命中清单的命令执行前弹二次确认
- 主要包含：`stop`、`whitelist off`、`allowlist off`、`permission` 变更、封禁类等

## 常用指令

```
list                          查看在线玩家
say 消息                      全服广播
op 玩家名 / deop 玩家名        设置 / 取消管理员
whitelist add 玩家名           加入白名单（等同 allowlist add）
whitelist remove 玩家名        移出白名单
kick 玩家名 [原因]             踢出
ban 玩家名 [原因]              封禁
pardon 玩家名                  解封
stop                          停止服务器
```

> 原版 BDS 对白名单命令同时接受 `whitelist` 与 `allowlist` 两种写法。

## 日志与排错

- 控制台输出同时写入应用日志，位置见 [11 安全与数据目录](11-security-data.md)
- 服务端崩溃重启、端口占用、下载失败等会在「性能监控」页或弹窗中提示
