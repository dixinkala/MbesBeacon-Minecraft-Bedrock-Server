# 09 联机与网络

[← 返回目录](README.md)

## 局域网联机

1. 服务器启动后，界面顶部显示 `服务器地址: <IP>:19132`，点 📋 复制
2. 同一 WiFi / 交换机的朋友在游戏内「服务器」→「添加服务器」
3. 填**你的局域网 IP** + 端口（默认 `19132`）

> `127.0.0.1` 只对本机有效，别把回环地址给别人。

## 公网联机

| 方案 | 说明 |
|---|---|
| 路由器端口映射 | 把公网 `UDP 19132` 转发到服务器内网 IP 的 `19132` |
| 内网穿透 | 用 frp / n2n / 商业穿透工具，把 UDP 端口映射到公网 |
| 云服务器 | 直接在公网机器上跑，注意安全组放行 UDP |

> BDS 使用 **UDP**，只放行 TCP 是连不上的。

## 防火墙

- 首次启动时 Windows 会弹防火墙提示，勾选「专用网络」并允许
- 若误点了「取消」，到「Windows Defender 防火墙 → 允许应用通过防火墙」里补上
- 云服务器需要同时配置安全组

## 端口

- 默认 `19132`（UDP），对应 `server.properties` 的 `server-port`
- 改端口：在「② 服务器配置」修改后保存并重启
- **端口占用检测**：启动前用 UDP 方式探测；被占用时会提示，而不是"启动了但连不上"

## 查看本机 IP

- 界面顶部直接显示并支持复制
- 或命令行 `ipconfig`，看「IPv4 地址」

## 常见连接失败排查

| 现象 | 排查顺序 |
|---|---|
| 好友连不上 | ① 是否同一网络 ② 是否填对局域网 IP ③ 防火墙 UDP ④ 服务器是否在运行 |
| 之前能连，突然不行 | IP 变了（DHCP），重新复制地址 |
| 公网连不上 | 端口映射是否 UDP、公网 IP 是否变动、运营商是否封端口 |
| 能连但进不去 | 白名单 / 在线模式 / 最大玩家数限制，见 [02](02-config.md)、[04](04-players-permissions.md) |
| 提示版本不匹配 | 客户端与服务端版本需一致，见 [01](01-install-update.md) |

## 远程管理（局域网 Web 访问）

默认只允许**本机**打开管理界面。需要在手机/另一台电脑上管理时：

1. 在运行程序的机器上打开「① 安装服务器」页底部的「🌐 远程管理」
2. 勾选「启用远程访问」并设置访问密码（至少 8 位），保存
3. **重启程序**（监听地址从 `127.0.0.1` 变为 `0.0.0.0`）
4. 在其他设备浏览器打开 `http://<局域网IP>:19100/`，输入密码登录

安全约定：

- 密码用 PBKDF2-SHA256 加盐存储，不保存明文
- 登录成功下发 `HttpOnly` + `SameSite=Strict` 会话 Cookie，12 小时滑动过期
- 同一 IP 5 分钟内失败 5 次会锁定 10 分钟
- Host 头仍按白名单校验（本机网卡 IP、主机名、用户额外配置的域名），防 DNS rebinding
- 会话只在内存中，重启程序后需要重新登录

> 传输是明文 HTTP，**只建议在可信局域网内使用**。需要公网访问时请配合内网穿透或反向代理（加 TLS），
> 并先把密码换成强口令。修改远程设置只能在运行程序的机器上进行。

## 公网联机（内网穿透）

BDS 走 **UDP 19132**，只有支持 UDP 的穿透方式可用（Cloudflare Tunnel 这类纯 TCP 方案不行）。

### 方式一：UPnP 自动端口映射

1. 「① 安装服务器」页底部 →「🌐 公网联机（内网穿透）」
2. 点「自动开启端口映射（UDP）」，成功后界面显示公网 IP
3. 把 `公网IP:19132` 发给好友；点「关闭端口映射」可撤销

路由器未开启 UPnP 或不支持时会给出提示，需要到路由器管理页手动把 `UDP 19132` 转发到本机。

> 如果显示的公网 IP 是 `10.x` / `192.168.x` / `172.16-31.x` / `100.64-127.x`，
> 说明处在双重 NAT 或运营商级 NAT（CGNAT）后面，互联网玩家通常连不上，请改用方式二。

### 方式二：内置穿透工具（推荐，无需自己装客户端）

安装页「🌐 公网联机」底部提供两种内置工具，程序会**从官方 GitHub Releases 下载并校验 SHA256**：

| 工具 | 需要什么 | 公网地址 |
|---|---|---|
| **playit** | playit.gg 账号（网页点一下领取） | 领取后在网页建 UDP 隧道，地址形如 `xxx.playit.gg:端口` |
| **frp** | 你自己的公网服务器（frps） | `服务器地址:远程端口`，启动后直接显示 |

playit 使用步骤：

1. 点「下载并安装」（自动下载 playit 与 playitd）
2. 点「生成领取链接」→ 打开链接登录并领取，然后在网页上创建一条 **UDP 隧道**指向本机 `19132`
3. 点「检查领取状态」，确认后点「启动」，界面显示隧道地址
4. 把地址发给好友；不用时点「停止」

frp 使用步骤：

1. 点「下载并安装 frpc」
2. 填服务器地址、服务端端口（默认 7000）、可选 token、远程端口（默认 19132）
3. 「保存」→「启动」，界面显示 `服务器地址:远程端口`

> 安全：两个工具都只从官方 Releases 下载并校验摘要，只在运行程序的机器上可操作；
> frp 可能被 Windows Defender 等杀软拦截，遇到「拒绝访问」请把 `tools\frp` 目录加入排除项。
> 许可：playit 为 BSD-2-Clause，frp 为 Apache-2.0。

### 方式三：外部穿透客户端

程序不内置任何第三方二进制，需要自行安装客户端并填写命令（`{port}` 会替换成服务器端口）：

| 客户端 | 命令示例 | 地址识别 |
|---|---|---|
| playit | `playit`（按其官网说明开启 UDP 隧道） | 日志里的 `xxx.playit.gg:端口` |
| ngrok | `ngrok tcp {port}` | `tcp://host:port` |
| frp | `frpc -c frpc.toml` | 日志里的 `IP:端口` |
| 自定义 | 任意命令 | 可在「公网地址正则」里写 `(?P<host>...)` 提取 |

- 启动后公网地址显示在界面，下方保留最近日志便于排查
- 客户端进程随程序退出被终止
- 安全：穿透命令只能在运行程序的机器上配置/启动（远程会话无权操作）
