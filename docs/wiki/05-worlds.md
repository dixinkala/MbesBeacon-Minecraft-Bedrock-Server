# 05 世界管理

[← 返回目录](README.md)

「⑤ 世界管理」操作服务器目录下的 `worlds/`。

## 世界列表

- 列出 `worlds/` 下所有世界目录
- 当前活动世界（`server.properties` 的 `level-name` 指向的那个）标记为「正在使用」
- 显示世界的基本信息（名称、游戏模式、难度等）

## 切换世界

1. 在列表中选择目标世界，点「切换」
2. 程序修改 `server.properties` 的 `level-name`（保留文件其它内容与格式）
3. **重启服务器后生效**

> 切换只改配置，不会移动或删除任何存档。

## 重命名 / 复制 / 删除

| 操作 | 说明 |
|---|---|
| 重命名 | 修改世界目录名；若该世界是活动世界，同步更新 `level-name` |
| 复制 | 复制一份存档用于备份或测试；重名会自动加后缀 |
| 删除 | 二次确认后删除世界目录，不可恢复 |

安全边界：

- 世界名做路径校验，含 `..`、绝对路径、分隔符的输入会被拒绝
- 目标路径必须位于 `worlds/` 之内（符号链接逃逸也会被拦）
- 危险目录（如系统目录）不会被当作世界删除

## 导入 / 导出存档

### 导出（📤）

- 把 `worlds/` 打包为 ZIP 下载
- 文件名：`{服务器名}_worlds_{YYYYmmdd_HHMMSS}.zip`
- 导出为流式下载，不占额外临时空间

### 导入（📥）

1. 选择 ZIP 存档
2. 程序先**自动备份**当前 `worlds/` 到 `worlds_backup_{时间戳}`
3. 需输入 `IMPORT` 二次确认
4. 校验 ZIP 结构与路径安全后解压
5. 自动刷新世界列表

支持四种常见包结构：`worlds/` 在根、单个世界目录、多世界平铺、以及带一层外层目录。

> 建议在服务器**停止**状态下导入/导出，避免文件占用导致失败。

## 与备份的区别

| | 世界管理 | 世界备份 |
|---|---|---|
| 对象 | 单个世界目录 | 整个 `worlds/` |
| 用途 | 切换 / 整理 / 迁移单个存档 | 定期快照与回滚 |
| 页面 | ⑤ 世界管理 | ⑥ 世界备份 |

详见 [06 备份与恢复](06-backups.md)。

## 常见问题

- **切换后进游戏还是旧世界**：配置改动需重启，请确认已重启。
- **导入后看不到世界**：ZIP 内层目录结构不标准；可解压后把世界目录放进 `worlds/` 再刷新。
- **删除后能恢复吗**：只能从备份恢复；删除前请确认已备份。
