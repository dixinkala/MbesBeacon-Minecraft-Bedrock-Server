# 04 玩家与权限

[← 返回目录](README.md)

## 在线玩家

- 需服务器**运行中**；点「🔄 刷新玩家列表」拉取当前在线玩家
- 每个玩家卡片显示玩家名与当前权限级别
- 可执行操作：

| 操作 | 说明 | 实现 |
|---|---|---|
| 设置权限 | 访客 `visitor` / 成员 `member` / 管理员 `operator` | 发送 `permission` 或写 `permissions.json`；运行中优先生效于进程 |
| 踢出 | 可填原因（可留空） | `kick <玩家> [原因]` |
| 加入黑名单 | 可填原因（可留空） | `ban <玩家> [原因]` |

部分操作会先写文件再发命令，保证「界面上能看到、也能解开」。

## 权限级别

| 级别 | 能做什么 |
|---|---|
| `visitor` | 只能看，不能改 |
| `member` | 可正常游戏，无管理命令 |
| `operator` | 拥有管理命令权限 |

权限保存在服务器目录的 `permissions.json`；玩家不在线时也可手动编辑。

## 白名单

- 列表显示已允许的玩家，可逐项移除
- 底部输入玩家名可直接加入，**不需要玩家在线**
- 服务器运行中通过命令生效；未运行时直接修改 `allowlist.json`
- 必须先在「② 服务器配置」把 `allow-list` 打开才会真正生效

## 黑名单（封禁）

- 显示已封禁玩家与原因，可点「解封」
- 底部可手动输入玩家名 + 原因直接加入，无需玩家在线
- 数据来源 `banned-players.json`

## IP 封禁

- 用于应对换号骚扰：读取/写入 `banned-ips.json`
- 可手动添加 IP 与原因，也可解除
- 运行中封禁会同时写文件并下发命令，避免"进程内生效、重启后丢失"

## 注意事项

| 场景 | 说明 |
|---|---|
| 离线模式 | `online-mode=false` 时第三方/离线账号可进入，白名单是唯一门槛 |
| 白名单不生效 | 检查 `allow-list=true` 是否已保存并**重启**服务器 |
| 命令无响应 | 服务器未运行时管理命令无法下发，但文件类操作仍可用 |
| 中文玩家名 | 支持；写入文件为 UTF-8 |
