# 02 服务器配置

[← 返回目录](README.md)

「② 服务器配置」页直接编辑服务器目录下的 `server.properties`。

## 常用项（约 17 项）

| 配置项 | 作用 | 注意 |
|---|---|---|
| `server-name` | 服务器名称 | 显示在玩家服务器列表 |
| `gamemode` | 游戏模式 | `survival` / `creative` / `adventure` / `spectator` |
| `difficulty` | 难度 | `peaceful` / `easy` / `normal` / `hard` |
| `allow-cheats` | 是否允许作弊指令 | 关闭后 OP 也无法用部分指令 |
| `max-players` | 最大玩家数 | 受服务端性能限制 |
| `online-mode` | 正版验证 | 关闭后离线/第三方账号可进入 |
| `allow-list` | 是否启用白名单 | 开启后仅白名单内玩家可进入 |
| `server-port` | 端口 | 默认 `19132`（UDP） |
| `server-portv6` | IPv6 端口 | 一般保持默认 |
| `level-name` | 活动世界目录名 | 由「⑤ 世界管理」切换时自动修改 |
| `level-seed` | 世界种子 | 仅影响新世界生成 |
| `view-distance` | 视距 | 越大越吃内存 |
| `tick-distance` | 模拟距离 | 影响生物活跃范围 |
| `player-idle-timeout` | 挂机踢出分钟数 | `0` 为不踢 |
| `default-player-permission-level` | 默认权限 | `visitor` / `member` / `operator` |
| `texturepack-required` | 强制使用服务器材质包 | |
| `language` | 服务端日志语言 | 不影响游戏内语言 |

## 高级模式

勾选「高级配置」后展示**全部 46 项**（含未在常用列表中的项），以通用 `key=value` 编辑器呈现，可直接改任意参数。

## 保存与生效

- 点「保存配置」写入文件；**需要重启服务器才生效**
- 「重新载入」从磁盘重新读取，放弃未保存的修改
- 服务器未安装时相关操作会提示先安装

## 格式与安全

- **保留原格式**：保存时保留注释行、空行与未在本页列出的自定义项，不会因为界面只显示常用项就把它们丢掉
- **数值校验**：端口、最大玩家数、视距等在输入时校验范围，非法值即时提示
- 重复键、`key = value`（等号两侧有空格）也能正确解析
- 写入采用原子替换，进程中断不会留下半截文件

## 多实例并行

程序可以同时管理多个服务器目录，并**同时运行**：

- 顶部「实例」下拉列出已收录的目录，`●` 表示运行中，`✓` 表示当前实例
- 「➕ 收录当前目录」把当前服务器目录加入列表；「✕ 移除实例」从列表移除（会先停止）
- 「▶ 启动 / ■ 停止」只作用于下拉选中的实例
- 选择另一个实例即切换"当前实例"：配置、世界、备份、包管理、控制台都会跟着切换

要点：

| 项 | 说明 |
|---|---|
| 端口 | 每个实例用自己的 `server.properties` 端口，互不冲突（同一个 UE 端口不能重复绑定） |
| 控制台 | 每个实例有独立缓冲；切换实例后控制台显示对应输出 |
| 玩家/性能 | 只针对当前实例（通过该实例的控制台解析） |
| 目录 | 实例必须是已安装的服务端目录（官方 exe 或 LeviLamina 的 `bedrock_server_mod.exe`） |
| 停止 | 移除/切换不会自动停止正在运行的实例，需要显式停止 |

## 配置历史与回滚

- 每次保存自动留存历史版本
- 可在「配置历史」中查看并回滚到任意历史版本
- 回滚同样需要重启服务器生效
