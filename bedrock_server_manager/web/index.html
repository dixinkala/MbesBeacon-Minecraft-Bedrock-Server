👋 欢迎使用！三步搭建你的 Minecraft 基岩版服务器
第一步　选择安装目录（下方「安装目录」输入框旁点击「浏览」）
第二步　选择版本（点击「下载版本」输入框旁的 ▼ 按钮）
第三步　点击「开始安装」，等待下载完成后自动启动
安装完成后可在「服务器控制台」管理服务器，在「玩家管理」管理玩家权限。

⚠ 警告：跳过 SSL 证书验证将使下载容易遭受中间人攻击，
可能导致下载被篡改的恶意服务器文件。仅在网络环境受信任时使用！
